# argus

> Network activity audit system. Argus is a fixed-model Real Time Flow Monitor designed to track and report on the status and performance of all network transactions seen in a data network traffic stream.

## Overview

This package provides `argus` for Termux. It is maintained as part of the i-HakLab package collection.

## Upstream source

- **Source:** [https://github.com/jasonxtn/Argus](https://github.com/jasonxtn/Argus)

## Installation

```bash
pkg update
pkg install argus
```
