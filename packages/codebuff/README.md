# codebuff

> AI coding agent that edits your codebase via natural language. Pair program with AI directly in your terminal.

## Installation

```bash
pkg install codebuff
```

## Info

| Field | Value |
|-------|-------|
| Version | `1.0.0` |
| Architecture | `aarch64` |
| Maintainer | [Ivam3](https://t.me/Ivam3_Bot) |
| Homepage | [Codebuff](https://codebuff.com) |

## Dependencies

`glibc, nodejs-lts, wget, tar`

## Usage

```bash
codebuff-installer
```

> Run the installer first to download and configure Codebuff, then use `codebuff` to start the AI coding agent.
