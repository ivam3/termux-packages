# markdown-viewer

> A simple CLI Markdown renderer for the terminal. Supports syntax highlighting, tables and more.

## Overview

This package provides `markdown-viewer` for Termux. It is maintained as part of the i-HakLab package collection.

## Upstream source

- **Source:** [https://github.com/ivam3/markdown-viewer](https://github.com/ivam3/markdown-viewer)

## Installation

```bash
pkg update
pkg install markdown-viewer
```

## Requirements

git, python, python-pip

