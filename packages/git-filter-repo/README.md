# git-filter-repo

> Quickly rewrite git repository history (filter-branch replacement with better performance and safety).

## Overview

This package provides `git-filter-repo` for Termux. It is maintained as part of the i-HakLab package collection.

## Upstream source

- **Source:** [https://github.com/newren/git-filter-repo](https://github.com/newren/git-filter-repo)

## Installation

```bash
pkg update
pkg install git-filter-repo
```

## Requirements

git, python3, python3-pip

```bash
git-filter-repo --help
```
