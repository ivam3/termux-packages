# d-tect

> Pentesting the modern web — D-TECT detects vulnerabilities in web applications including XSS, SQLi, CSRF and more.

## Installation

```bash
pkg install d-tect
```

## Dependencies

`python, python-pip, git`

## Usage

```bash
d-tect-installer
```

> Run the installer first to set up D-TECT, then use `d-tect [options]` to scan web applications for vulnerabilities.
