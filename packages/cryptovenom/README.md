# cryptovenom

> The crypto framework — an all-in-one cryptography tool that lets you encrypt, decrypt, hash, and analyze data using many algorithms.

## Overview

This package provides `cryptovenom` for Termux. It is maintained as part of the i-HakLab package collection.

## Upstream source

- **Source:** [https://github.com/lockedbyte/CryptoVenom](https://github.com/lockedbyte/CryptoVenom)

## Installation

```bash

```
