# phonesploit

> An all-in-one hacking tool to remotely exploit Android devices via ADB with a simple interactive menu.

## Overview

This package provides `phonesploit` for Termux. It is maintained as part of the i-HakLab package collection.

## Upstream source

- **Source:** [https://github.com/aerosol-can/PhoneSploit](https://github.com/aerosol-can/PhoneSploit)

## Installation

```bash
pkg update
pkg install phonesploit
```

## Requirements

git, python

phonesploit --help
