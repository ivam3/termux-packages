# zcode

> ZCode — AI vibe coding harness (GLM-5.3) native glibc aarch64 for termux-x11.

## Installation

```bash
pkg install zcode
```

## Info

| Field | Value |
|-------|-------|
| Version | `3.10.2-1` |
| Architecture | `aarch64` |
| Maintainer | [Ivam3](https://t.me/Ivam3_Bot) |
| Homepage | [ZCode](https://zcode.z.ai) |

## Dependencies

`x11-repo, glibc, curl, tar, jq, patchelf-glibc, termux-x11, fontconfig-glibc, freetype-glibc, gnome-themes-extra`

## Usage

```bash
zcode --help
```

> Static help, no X required. For GUI: `termux-x11 :0 & DISPLAY=:0 zcode [path]`
