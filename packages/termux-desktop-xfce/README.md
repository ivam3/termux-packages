# termux-desktop-xfce

> A Meta-package and data, themes, icons and wallpapers to configure a desktop environment for Termux with xfce4 as window manager.

## Installation

```bash
pkg install termux-desktop-xfce
```

## Dependencies

`termux-x11-nightly, xfce4, xfce4-terminal, xfwm4, dbus, at-spi2-core`

## Usage

```bash
desktop [options]
```
