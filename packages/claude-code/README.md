# claude-code

> Anthropic Claude Code — autonomous AI coding agent in your terminal. Understands your codebase and works with you.

## Installation

```bash
pkg install claude-code
```

## Info

| Field | Value |
|-------|-------|
| Version | `1.0.37` |
| Architecture | `aarch64` |
| Maintainer | [Ivam3](https://t.me/Ivam3_Bot) |
| Homepage | [Claude Code](https://claude.ai/code) |

## Dependencies

`glibc, nodejs-lts, wget, tar`

## Usage

```bash
claude-code-installer
```

> Run the installer first to download and configure Claude Code, then use `claude-code` to start the AI coding agent.
