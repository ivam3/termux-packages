# antigravity-cli

> Google Antigravity CLI — an autonomous AI coding agent that runs entirely in your terminal. Powered by Gemini.

## Installation

```bash
pkg install antigravity-cli
```

## Info

| Field | Value |
|-------|-------|
| Version | `1.1.0` |
| Architecture | `aarch64` |
| Maintainer | [Ivam3](https://t.me/Ivam3_Bot) |
| Homepage | [Antigravity](https://antigravity.dev) |

## Dependencies

`glibc, nodejs-lts, wget, tar`

## Usage

```bash
antigravity-cli-installer
```

> Run the installer first to download and configure Antigravity CLI, then use `antigravity-cli` to start the AI coding agent.
