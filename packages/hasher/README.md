# hasher

> Fast CLI tool to hash strings or files using multiple algorithms (md5, sha1, sha256, sha512 and more).

## Overview

This package provides `hasher` for Termux. It is maintained as part of the i-HakLab package collection.

## Upstream source

- **Source:** [https://github.com/CiKu370/hasher](https://github.com/CiKu370/hasher)

## Installation

```bash
pkg update

```
