# DoS-A-Tool

> A multipurpose Denial of Service toolkit designed to automate most of the DoS attacks currently available on the internet.

## Overview

This package provides `dos-a-tool` for Termux. It is maintained as part of the i-HakLab package collection.

## Upstream source

- **Source:** [https://github.com/ivam3/DoS-A-Tool](https://github.com/ivam3/DoS-A-Tool)

## Installation

```bash
pkg update
pkg install dos-a-tool
```

## Requirements

perl, dos2unix

## Usage

```bash
dos-a-tool --help
```

For the complete command reference, see the upstream documentation.
