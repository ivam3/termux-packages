# mimocode

> AI coding agent tailored for Termux and Android. A lightweight alternative to full AI agents optimized for mobile ARM devices.

## Installation

```bash
pkg install mimocode
```

## Info

| Field | Value |
|-------|-------|
| Version | `0.1.0` |
| Architecture | `aarch64` |
| Maintainer | [Ivam3](https://t.me/Ivam3_Bot) |
| Homepage | [mimocode](https://github.com/Ivam3/mimocode) |

## Dependencies

`glibc, nodejs-lts, wget, tar`

## Usage

```bash
mimocode [options]
```
