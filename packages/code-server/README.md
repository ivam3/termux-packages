# code-server

> VS Code in the browser — run Visual Studio Code on a remote server and access it via a web browser.

## Installation

```bash
pkg install code-server
```

## Info

| Field | Value |
|-------|-------|
| Version | `4.96.4` |
| Architecture | `aarch64` |
| Maintainer | [Ivam3](https://t.me/Ivam3_Bot) |
| Homepage | [code-server](https://coder.com/docs/code-server) |

## Dependencies

`glibc, nodejs-lts, wget, tar`

## Usage

```bash
code-server-installer
```

> Run the installer first, then use `code-server` to start VS Code accessible from your browser.
