# omniroute

> Smart AI Router with 160+ providers, auto-fallback, and OpenAI-compatible APIs. Termux-native adaptation with playwright-core mock for Android platform compatibility.

## Overview

This package provides `omniroute` for Termux. It is maintained as part of the i-HakLab package collection.
