# omniroute

> Multi-proxy routing manager for Termux — route traffic through TOR, SOCKS5, HTTP and chain proxies with a single command.

## Installation

```bash
pkg install omniroute
```

`python, curl, wget, tor, proxychains-ng`

