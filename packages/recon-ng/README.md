# recon-ng

> A full-featured reconnaissance framework designed with the goal of providing a powerful environment to conduct open source web-based reconnaissance quickly and thoroughly.

## Overview

This package provides `recon-ng` for Termux. It is maintained as part of the i-HakLab package collection.

## Upstream source

- **Source:** [https://github.com/lanmaster53/recon-ng](https://github.com/lanmaster53/recon-ng)

## Installation

```bash
pkg update
pkg install recon-ng
```

## Requirements

git, rust, python, libxml2, libxml2-utils, libxslt, python-lxml
