# finalrecon

> FinalRecon is an all in one automatic web reconnaissance tool written in python.

## Overview

This package provides `finalrecon` for Termux. It is maintained as part of the i-HakLab package collection.

## Upstream source

- **Source:** [https://github.com/thewhiteh4t/FinalRecon](https://github.com/thewhiteh4t/FinalRecon)

## Installation

```bash
pkg update
pkg install finalrecon
```

git, python, python-pip, python-cryptography
