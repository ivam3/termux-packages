# xml2axml

> Encoding xml to axml OR decoding axml to xml — essential for Android APK reverse engineering.

## Overview

This package provides `xml2axml` for Termux. It is maintained as part of the i-HakLab package collection.

## Upstream source

- **Source:** [https://github.com/codyi96/xml2axml](https://github.com/codyi96/xml2axml)

## Installation

```bash
pkg update
pkg install xml2axml
```

## Requirements

curl, openjdk-21
