# openclaw

> OpenRouter-powered AI coding agent for Termux. Access multiple AI models (GPT-4, Claude, Mistral) from a single terminal interface.

## Installation

```bash
pkg install openclaw
```

`glibc, nodejs-lts, wget, tar`

## Usage

```bash
openclaw [options]
```
