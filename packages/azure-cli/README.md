# azure-cli

> Microsoft Azure Command-Line Interface — manage Azure services from the terminal.

## Installation

```bash
pkg install azure-cli
```

## Dependencies

`python, python-pip, libffi, openssl`

## Usage

```bash
azure-cli-installer
```

> Run the installer first, then use `az [command]` to manage Azure services from the terminal.
